# База знаний

В `sources/` лежат русскоязычные конспекты первоисточников. Учебные примеры в них помечены явно. Цитата в чате ведёт к разделу конспекта и ссылке на первоисточник. Официальных учебных регламентов УрФУ и ИРИТ-РТФ в первоначальной подборке нет.

## Обновление корпуса

1. Добавьте файл UTF-8 `.md` или `.txt` в `sources/`. Разметьте смысловые разделы заголовками `## stable-id | Название раздела`. Подразделы можно обозначать через `###`. Оставляйте пояснение к списку рядом со списком, а номера пунктов и условия — рядом с правилами. Для PDF с текстовым слоем можно извлечь черновик локально командой `pdftotext -layout source.pdf draft.txt`, затем сверить порядок текста с оригиналом и подготовить конспект или допустимые выдержки.
2. В `manifest.json` запишите `id`, `title`, `publisher`, `version`, `url`, `description` и `file`. Версию раздела можно пояснить в тексте, а точную ссылку указать в `section_urls` по идентификатору раздела. Для официального локального документа можно задать `"scope": "institutional"`. Стабильные ID состоят из строчных латинских букв, цифр и дефисов.
3. Из корня выполните `python scripts/build_index.py`. Сборка сохраняет смысловые блоки размером до 1600 символов и формирует `index.json`. Если отдельный абзац или блок превышает этот лимит, разбейте его по смыслу. Команда `python scripts/build_index.py --check` проверяет актуальность подготовленного индекса. После изменений пересоберите векторный индекс по инструкции в корневом README.
