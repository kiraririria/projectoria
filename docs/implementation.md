# Заметки о реализации

## Референс

Основной референс — [«Параграф» (`arniByte/legal_adviser`), ревизия `e20686f`](https://github.com/arniByte/legal_adviser/tree/e20686f). С разрешения автора адаптированы адресуемые фрагменты, BM25 с эмбеддингами и слиянием рангов, необязательный реранкер, расширенный поиск, проверка привязки утверждения к источнику и передача стадий по SSE. Интерфейс продолжает идею одноколоночного диалога, центральной анимации и сносок с отдельным просмотром источника. Параграф хранит диалоги локально, этот подход тоже сохранён. Предметная модель, код и корпус написаны для проектного наставника. Репозиторий `kiraririria/urfu-rag` помог определить темы для подбора первоисточников.

Из `la_kb.py` и `la_retrieval.py` взят принцип разбиения по структурным единицам. Локальный реестр, подбор редакций на дату и правила проверки реквизитов договоров в данной предметной области не нужны. `la_pipeline.py`, `la_llm.py` и `la_verify.py` подсказали ограниченный цикл поиска и исправления. Потоковый интерфейс `app/server.py`, статический клиент и нативный Python-билдер задают основу для Vercel. Фрагменты и векторы готовятся до сборки, поэтому холодный старт не требует сетевой индексации и записи на файловую систему сервера.

## Обработка запроса

- `app/retrieval.py` использует русский Snowball-стемминг и набор профессиональных сокращений. Короткое продолжение получает часть терминов предыдущего вопроса. Независимый запрос главным образом ранжируется по собственным словам.
- `app/pipeline.py` передаёт модели вопрос, сокращённую историю и ограниченный набор кандидатов как данные в JSON. Контекст для повторного прохода расширяется по доступным фрагментам и уточнённым поисковым терминам. Дорогие операции на запрос ограничены одним эмбеддингом, одним опциональным реранкингом и двумя генерациями.
- Строки с явными командами модели скрываются из контекста. Проверка исключает их из цитат. Правило покрывает типовые формулировки подмены инструкций, поэтому при пополнении базы материалы всё равно нужно просматривать.
- `app/verify.py` требует реальные идентификаторы из переданного контекста. Утверждение должно сопровождаться выдержкой из указанного фрагмента. Написанное цифрами значение должно быть в выдержках, заголовках соответствующих разделов или условиях, сообщённых пользователем. Практические рекомендации имеют собственный раздел. Проверка не измеряет логическое следование вывода из цитаты и не сверяет числа, написанные словами.
- Внешние ссылки в карточках берутся из индекса. Открываемый фрагмент — конспект первоисточника, а помеченная выдержка взята из конспекта. Модель не выполняет действий через инструменты и не получает ключ OpenRouter в промпте.
- Шрифт Onest поставляется локально в двух поднаборах Google Fonts. Условия распространения сохранены в [OFL-Onest.txt](../app/static/fonts/OFL-Onest.txt).

## Векторы и модели

В поставку входит индекс BGE-M3, построенный локально с публичными весами [ONNX INT8](https://huggingface.co/onnx-community/bge-m3-ONNX/tree/25b9af8e87a38eb120cfe87125383677b9cd309e). Для воспроизведения нужны `tokenizer.json` и `onnx/model_int8.onnx` из этой ревизии. Сохраните оба файла в один внешний каталог, затем выполните команды ниже. Весов и ONNX Runtime в Vercel-пакете нет.

```powershell
.venv\Scripts\python -m pip install onnxruntime==1.32.0 tokenizers==0.23.3
.venv\Scripts\python -m scripts.build_vectors --onnx-dir C:\path\to\bge-m3
```

В рабочем приложении вектор запроса получает OpenRouter через `/embeddings`. Готовые векторы содержат ID модели и отпечаток входных текстов. Квантованные и размещённые у провайдера веса используют одно пространство BGE-M3, но могут давать разные значения. Чтобы использовать одного провайдера для запроса и корпуса, выполните `python -m scripts.build_vectors` с ключом. Для смены модели этот шаг обязателен.

По каталогу OpenRouter на 23 ноября 2026 года Gemini 2.5 Flash-Lite поддерживает JSON-ответы и стоит $0,10 за миллион входных и $0,40 за миллион выходных токенов. BGE-M3 стоит $0,01 за миллион токенов и рассчитан на многоязычный поиск. Опциональный многоязычный Qwen3 Reranker 0.6B стоит $0,20 за миллион токенов. Его оставили выключенным до измеримого выигрыша на этом корпусе, поскольку он добавляет сетевой запрос. Опубликованные задержки зависят от маршрута. Качество генерации на русском и задержку конкретного развёртывания оценивают отдельным прогоном. [Gemini 2.5 Flash-Lite](https://openrouter.ai/google/gemini-2.5-flash-lite/pricing) · [BGE-M3](https://openrouter.ai/baai/bge-m3) · [Qwen3 Reranker 0.6B](https://openrouter.ai/qwen/qwen3-reranker-0.6b)

## Состояние проекта

- 11 документов, 51 фрагмент. Локальные регламенты УрФУ в начальную подборку не входят.
- Векторный индекс собран, исходники базы и оба индекса находятся в `knowledge/`. Полностью локальный режим поиска для проверок доступен без ключа. Ответы через реальную модель требуют `OPENROUTER_API_KEY`.
- Пройдены 35 автотестов. Лексический и локальный гибридный поиск нашли ожидаемые источники для всех 28 вопросов с опорой на базу. Интерфейс проверен в Chromium на десктопной и мобильной ширине. SSE, цитаты, продолжение диалога и ошибки провайдера проверены с подменой OpenRouter. Генерация по реальному API требует отдельной проверки.
- Конфигурация Vercel подготовлена. Попытка сборки остановилась на запросе авторизации. Облачная сборка и публикация остаются непроверенными.
