# Как устроена Проектория

## Что взяли из «Параграфа»

«Параграф» отвечает на вопросы по договорам, регламентам и законам. Проектория помогает студентам с проектной методологией. С разрешения автора Проектория адаптировала подход к поиску по фрагментам, сноскам и проверке источников. [Код «Параграфа», ревизия e20686f](https://github.com/arniByte/legal_adviser/tree/e20686f)

| Этап | «Параграф» | Проектория |
| --- | --- | --- |
| База и поиск | Гибридный поиск по структурированным документам. Короткие документы могут передаваться целиком. Реестр помогает учесть контрагентов, номера, даты и редакции | Гибридный поиск по конспектам проектных практик. Используются русский стемминг, словарь терминов и готовый индекс BGE-M3 |
| Диалог | Последние реплики дополняют поисковый запрос | Предыдущий вопрос добавляется при явном продолжении. На реакцию без нового вопроса ассистент просит уточнить, что разобрать |
| Ответ и проверка | Модель формулирует ответ. Код сверяет положения, числа, даты и реквизиты. Дополнительный проход может убрать лишние фразы | Модель выбирает абзацы. Сервер сверяет их идентификаторы и показывает текст базы со сносками. Для запроса о конкретной команде есть уточнение о недостающих вводных |
| Сбой модели | При сбое или неустранённой ошибке может показать положение источника | В рамках общего лимита возможна одна дополнительная попытка. При сбое показывается связанный фрагмент, если его можно найти по словам |

## От вопроса к источнику

Для коротких вопросов вида «Что такое X?» `app/definitions.py` сначала ищет в тексте базы определение точного термина и его явных синонимов. На `Srum` ассистент просит подтвердить `Scrum`. В текущем конспекте описаны команда и события Scrum. Запрос определения Scrum получает отдельный ответ об отсутствии определения.

1. `app/retrieval.py` объединяет ранги полнотекстового и векторного поиска. Опциональный реранкер уточняет порядок кандидатов. При сбое эмбеддингов остаётся поиск по словам.
2. `app/pipeline.py` передаёт модели ограниченный список абзацев с идентификаторами. Предыдущий вопрос помогает разобрать явное уточнение. Ответы ассистента из истории в подборку не входят.
3. `app/verify.py` принимает только идентификаторы из этого списка. Сервер вставляет исходный текст в том порядке, который выбрала модель, и выделяет его в карточке источника. Строки, похожие на инструкции модели, исключаются вместе с абзацем.
4. `app/server.py` передаёт интерфейсу статусы и результат через SSE. Повторный подбор при временной ошибке либо расширение поиска выполняется в пределах общего срока. Временный сбой может оставить пользователю тематический абзац с пометкой о недоступности модели. Для короткого запроса определения такой подстановки нет.

Цитаты берутся из русскоязычных конспектов. Ссылки в карточках ведут к первоисточникам, указанным в базе. Проверка качества оценивает, подходит ли выбранная выдержка к вопросу. [Правила подготовки материалов](../knowledge/README.md) · [Проверка качества](quality.md)

## Векторы и модели

Для выбора выдержек используется DeepSeek V4.1 Flash через OpenRouter. Модель возвращает короткий JSON со статусом и списком идентификаторов. Для DeepSeek V4 отдельно отключается режим рассуждений. Сервер использует ограничение по времени и режим маршрутизации по задержке. [DeepSeek V4.1 Flash](https://openrouter.ai/deepseek/deepseek-v4.1-flash)

В репозитории есть файловый индекс BGE-M3. Он хранит модель, отпечаток входных текстов и векторы. При несовпадении с документами или моделью остаётся поиск по словам.

Исходный индекс собран с публичными весами BGE-M3 ONNX INT8. Для повторной сборки положите `tokenizer.json` и `onnx/model_int8.onnx` в один каталог. [Веса и токенизатор](https://huggingface.co/onnx-community/bge-m3-ONNX/tree/25b9af8e87a38eb120cfe87125383677b9cd309e)

```bash
python -m pip install onnxruntime==1.32.0 tokenizers==0.23.3
python -m scripts.build_vectors --onnx-dir /path/to/bge-m3
```

Вектор запроса получает OpenRouter. Для индекса и запросов можно использовать одного провайдера, пересобрав векторы через `python -m scripts.build_vectors` с настроенным ключом. При смене модели эмбеддингов индекс нужно пересобрать.

В базе 11 документов и 51 фрагмент. Доступность генерации на рабочем экземпляре можно проверить вопросом из набора. Публичный `/api/health` показывает настроенную модель и состояние индекса. [Демо](https://projectoria.vercel.app) · [Состояние API](https://projectoria.vercel.app/api/health)
